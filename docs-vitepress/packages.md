## Built with dbverse

These packages and projects use the same database-backed analysis model.

- [GiottoDB](https://github.com/dbverse-org/GiottoDB) supports database-backed
  spatial omics analysis in the Giotto ecosystem.
- [Giotto](https://github.com/drieslab/Giotto) is a spatial multi-omics analysis
  toolbox.
- [GiottoSeq](https://github.com/giotto-suite/GiottoSeq) supports genomic data
  analysis in the Giotto framework.
